# PhonMatch

Telegram-бот для подбора смартфонов по ответам на квиз. Сейчас реализованы приветствие и регистрация, а квиз и подбор находятся в разработке. REST API содержит проверку доступности.

## Запуск

Нужны Python 3.11+ и запущенный PostgreSQL с созданной базой `phonmatch`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите BOT_TOKEN от BotFather и параметры PostgreSQL в .env
alembic revision --autogenerate -m "initial"
alembic upgrade head
python -m bot.main
```

Первая команда Alembic создаёт файл миграции: проверьте его перед применением и сохраните в репозитории. Выполняйте миграции до первого запуска бота: бот создаёт отсутствующие таблицы при старте, но `create_all` не заменяет миграции и не обновляет существующую схему. Настройки, включая `BOT_TOKEN`, нужны и для Alembic.

Запуск заготовки API: `uvicorn api.main:app --host 0.0.0.0 --port 8000`. Проверка: `GET /health`. Настройки `API_HOST` и `API_PORT` зарезервированы для будущего программного запуска API; параметры команды uvicorn задаются отдельно.

## Каталог смартфонов

После применения миграций загрузите первоначальный каталог (команды выполняются из корня проекта):

```bash
python scripts/seed.py load
python scripts/seed.py stats
python scripts/seed.py load --update  # обновляет характеристики и заменяет цены
python scripts/seed.py clear          # удаляет ВСЕ смартфоны и цены без подтверждения
```

Цены в seed-файле — ориентировочные примеры для 2025 года, не исторические котировки и не текущие предложения указанных магазинов. Оценки — приблизительные заготовки для разработки, не результаты независимого тестирования; характеристики и цены зависят от региона и модификации устройства и требуют проверки перед применением в рекомендациях.

## Квиз и подбор

Выберите тип квиза через `/start`. Ответы и результаты завершённого квиза сохраняются в БД; незавершённые сеансы остаются в истории. При `/start` во время прохождения бот запросит подтверждение прерывания. Цены в карточках — минимальные цены в наличии в каждом выбранном канале; данные seed-файла ориентировочные. Если оценка характеристики отсутствует, при скоринге используется нейтральное значение 5 из 10.

FSM хранится в памяти процесса: после перезапуска бота незавершённый квиз нужно начать заново. Защита от одновременных нажатий работает внутри одного процесса; для нескольких экземпляров бота необходимы общее FSM-хранилище и распределённая блокировка.

Проверки без PostgreSQL: `BOT_TOKEN=123456:ABC python -m unittest discover -s tests -v`.
